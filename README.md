# Sales Performance Analytics Dashboard

## Project overview

An interactive Power BI dashboard built to explore retail sales performance and help users examine trends across time, regions, products and customer segments.

The project demonstrates my developing skills in data preparation, business intelligence, data visualisation and communicating analytical findings.

## Business questions

- How do sales change over time?
- Which regions contribute the most to sales?
- Which products perform best?
- How are sales distributed across customer segments?
